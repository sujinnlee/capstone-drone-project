## 01. 프로젝트 소개 | Overview

### 프로젝트 개요

드론 영상에서 산불 연기를 탐지하고, 주변 지리정보를 결합하여 경량 VLM이 재난 상황을 한국어로 설명하는 시스템을 개발하고 있습니다.

드론에서 계산한 위치에는 오차가 발생할 수 있습니다. 따라서 단일 좌표만으로 연기 발생 위치를 확정하기보다, **위치 불확실성을 고려한 GIS 정보와 3단계 판정 결과**를 활용하도록 설계했습니다.

| 구분 | 내용 |
|---|---|
| 프로젝트명 | EdgeEye (엣지아이) |
| 과제 유형 | 기업 연계 캡스톤디자인 |
| 진행 기간 | 2026.09 ~ 진행 중 |
| 팀 구성 | 3명 |
| 개발 분야 | Computer Vision · VLM · GIS |
| 담당 분야 | 데이터 분석 및 지리정보 기반 위치 판정 |

### 주요 목표

- 드론 영상에서 연기 영역 탐지
- 탐지 위치와 주변 지리정보 결합
- 위치 불확실성에 따른 **확정·모호·미확정** 판정
- 판정 결과를 활용한 경량 VLM의 한국어 상황 해설

## 05. 주요 문제 해결 | Problem Solving

### GPS 데이터 신뢰성 문제

**Problem — 문제 발견**

초기에는 드론 이미지에 기록된 GPS 좌표를 실제 촬영 위치로 활용할 계획이었습니다.

그러나 드론 이미지 14,067장의 위치정보를 분석한 결과, **6,977장(49.6%)에서 동일한 GPS 좌표가 반복**되는 것을 확인했습니다.

서로 다른 촬영 지역에서도 해당 좌표가 반복되어 실제 위치 계산에 그대로 사용하기 어렵다고 판단했습니다.

**Solution — 대응 방법**

- GPS 좌표의 반복 패턴과 데이터 분포 분석
- 신뢰하기 어려운 좌표를 실제 촬영 위치 계산에서 제외
- 시연 지역을 재선정하고 가상 기준 위치를 활용하도록 실험 설계 변경
- 실제 확인된 값과 실험상 가정한 값을 구분하여 관리

**Result — 결과**

GPS 메타데이터의 신뢰성 문제를 발견하고, 잘못된 위치정보가 이후 GIS 분석과 AI 해설에 반영되지 않도록 데이터 처리 기준을 마련했습니다.

### 위치 불확실성을 고려한 판정

**Problem**

드론 영상에서 계산한 위치 주변에 서로 다른 용도지역이 포함될 경우, 특정 장소에서 연기가 발생했다고 단정하기 어렵습니다.

**Solution**

10m, 30m, 50m, 100m의 가상 오차 반경을 설정하고, 주변 용도지역 분포에 따른 위치 판정 기준을 모의 실험으로 검토했습니다.

**Result**

위치 불확실성이 커질수록 확정 판정을 더 신중하게 내리도록 기준을 설계했습니다.

> 해당 실험은 가상 오차 반경을 활용한 모의 실험이며, 실제 드론 GPS 측정 정확도를 의미하지 않습니다.
